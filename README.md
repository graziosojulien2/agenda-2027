# Agenda 2027 — Gratzob

Agenda une page par jour, connecté à Google Agenda (dans les deux sens).

- Site : https://graziosojulien2.github.io/agenda-2027/
- Les photos et les notes (missions, notes, niveau du jour) ne sont **pas** dans ce dépôt :
  elles sont dans le Google Drive du compte connecté, dossier « Agenda 2027 ».
- `data.js` : contenu fixe extrait du PDF (fêtes, pensées, citations, bandeaux).
- `config.js` : identifiant client OAuth Google (non secret).
